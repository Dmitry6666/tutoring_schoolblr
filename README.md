# Орбита — сайт образовательного центра

Одностраничный сайт репетиторского центра для школьников 1–11 классов: школьные
предметы, подготовка к экзаменам и программирование. Свёрстан с нуля на React,
TypeScript и обычном CSS, без UI-библиотек и CSS-фреймворков.

> Это демонстрационный проект. Название «Орбита», контакты, преподаватели, отзывы,
> цены и обещания программ — примеры. Перед публикацией замените их на реальные
> данные и проверьте юридические документы.

## Быстрый старт

```bash
npm install
npm run dev
```

Сайт откроется на `http://localhost:5173/`.

Другие команды:

```bash
npm run build    # проверка TypeScript и production-сборка в dist/
npm run preview  # локальный просмотр production-сборки
```

Требуется Node.js 20.19+ или 22.12+ (ограничение Vite 8).

## Форма заявки

Форма отправляет JSON на endpoint из переменной окружения `VITE_FORM_ENDPOINT`:

```env
VITE_FORM_ENDPOINT=https://example.com/api/leads
```

Тело запроса:

```json
{
  "name": "Анна",
  "phone": "+7 (999) 123-45-67",
  "grade": "5–8 класс",
  "direction": "Программирование",
  "consent": true,
  "source": "orbita-website"
}
```

Endpoint должен ответить кодом 2xx. Ошибки сети или ответ 4xx/5xx показывают
пользователю сообщение с предложением позвонить.

Если переменная не задана, форма работает **в демонстрационном режиме**: она
проводит валидацию и показывает экран успеха, но никуда не отправляет данные.
Подойдёт Formspree, Getform, CRM-вебхук или собственный backend.

Переменная встраивается на этапе сборки. После изменения `.env` пересоберите проект.
Пример переменной — в `.env.example`; сам `.env` не попадает в git.

## Юридические ограничения

- Политика обработки персональных данных в `src/components/PrivacyModal.tsx` —
  шаблон. Её должен проверить юрист с учётом 152-ФЗ, фактического состава данных,
  сроков хранения, используемых сервисов и политики cookie/аналитики.
- Формулировка согласия в форме и ссылка на политику должны соответствовать
  реальному процессу обработки данных.
- Название центра, юридическое лицо, контакты и обещания программ — вымышленные.
- Отзывы и имена детей вымышлены. Не публикуйте реальные отзывы без согласия.
- Если добавляете аналитику, cookie или внешние виджеты, обновите политику и
  настройки согласия.

## Технические детали

- React 19 + Vite 8 + TypeScript.
- Шрифты `Unbounded Variable` и `Manrope Variable` подключены локально через
  `@fontsource-variable`, внешние запросы к Google Fonts не выполняются.
- Иконки — `lucide-react`.
- Нет роутера: навигация по якорям одной страницы.
- Нет backend/CMS: все данные лежат в `src/data`.
- Модальные окна закрываются по Escape и клику по фону, удерживают фокус и
  возвращают его на кнопку открытия.
- Анимации отключаются при `prefers-reduced-motion: reduce`.
- Адаптивность проверена на ширинах 320, 390, 768, 1024 и 1440 px.

## Деплой

Соберите проект (`npm run build`) и загрузите содержимое `dist/` на любой
статический хостинг: Netlify, Vercel, Cloudflare Pages, GitHub Pages, nginx.
Так как роутера нет, дополнительная настройка fallback-маршрутов не требуется.

Если форма должна отправлять заявки, задайте `VITE_FORM_ENDPOINT` в настройках
сборки хостинга и пересоберите сайт.
